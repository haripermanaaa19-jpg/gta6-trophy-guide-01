**Leonida Legend** is an offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. It carries the official list exactly as PlayStation publishes it (names, descriptions, grades, the 28 hidden trophies), and adds what a trophy hunter actually needs: a guide for every trophy written for this app with its sources named, a six-stage roadmap to the platinum derived from the official descriptions, and clear flags on the trophies that can be missed or run on story windows — above all the Chapter 1 meditation inside Positive Mental Attitude. Progress is a checklist saved in your browser (localStorage), with per-trophy counters for the tracked totals, kind and grade filters, a spoiler setting that keeps hidden trophies masked until they are earned, and export/import so a run can move between machines. Everything is static files under `app/`; it works with the network off and sends nothing anywhere. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
