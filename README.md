An offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: the official list with grades, a cited guide for every trophy, a platinum roadmap with missable flags, progress saved in the browser, and export/import. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
